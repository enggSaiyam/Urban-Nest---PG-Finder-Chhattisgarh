# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/enggSaiyam/Urban-Nest---PG-Finder-Chhattisgarh.git
```

Go inside project

```bash
cd Urban-Nest---PG-Finder-Chhattisgarh
```

Install dependencies

```bash
npm install
```

Run project

```bash
npm run dev
```
